# 首次會員註冊欄位精簡

基準：ee228f98e96fa57a300c5c2113c30b5c2280470b。

一般會員必填：姓名、手機、Email、密碼、會員條款、隱私權政策。
店家會員必填：聯絡人姓名、手機、Email、密碼、店家會員條款、隱私權政策、店家名稱、店家身分類型。

完整 member-schema.js 欄位與管理欄位保留；首次表單使用獨立欄位投影與驗證。API 同步採用首次規則，仍允許舊格式合法的選填資料。一般會員 displayName 未提供時使用姓名；店家顯示名稱未提供時使用店名（帳號顯示名稱最多 120 字）。既有店家待綁定名稱使用本次店名，不收重複店名或店家 ID，仍無綁定權限。

一般會員的暱稱、區域、出生年月、性別、聯絡偏好與通知意願，以及店家職稱、聯絡方式、店家顯示名稱、分類、電話、地址、營業區域、介紹、網站社群、營業時間、圖片與通知意願，保留資料結構供後續會員資料補充工作包使用。本包未新增補填頁或編輯 API。

無 migration，無資料庫欄位、既有會員或店家資料異動。不更改密碼雜湊、Session、Cookie、登入登出、me、Rate Limit 或 Origin 規則。

本包針對會員 Authentication 與 DOM 表單測試共 56 項通過。Production 驗證由既有 members:auth-production 指令執行，使用最小欄位的一般會員、既有店家、新店家，逐筆註冊、獨立連線讀回、登入、me、登出及清理；以不輸出資料的 DB 摘要核對其他既有會員與店家會員資料未變。Production 結果須依實際部署 log 回報，不以單元測試代替。

施工通過仍須使用者人工驗收。
