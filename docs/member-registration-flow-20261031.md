# 會員註冊流程修正

- Neon 為正式會員資料來源。
- 註冊成功通知信取消；Google Sheet 會員同步退出註冊主流程，既有程式檔保留。
- 一般會員最小必填：姓名、手機、Email、密碼、會員服務條款、隱私權與個人資料告知。
- 店家會員另必填店家名稱及六大店家申請類型：美食餐飲、購物零售、居家服務、醫療保健、生活服務、教育休閒。
- 店家申請類型保存於 registration_profile.shopCategory，沒有 destructive migration。
- 店家仍以 application 狀態建立，shop_bound=false，不變更公開店家資料。
- Email／手機驗證暫不啟用，既有欄位保留並列正式收費階段待辦。
- 註冊頁提示只保留「免費開放註冊，填寫基本資料即可加入」。
